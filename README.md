# ジャズ・ステップ 🎷

ジャズ初心者が「聴いて・わかって・弾いてみる」まで進める、スマホ向けの学習アプリです。
インストール不要。ブラウザで `index.html` を開くだけで動き、**音もアプリ内で鳴ります**（音源ファイル不要）。

## アプリの画面（3つだけ）

| タブ | できること |
|---|---|
| **学ぶ** | 6つのレッスンをカード形式で1枚ずつ進める。各レッスン3〜5分 |
| **耳トレ** | 和音を聴いて「明るい？切ない？緊張？」を当てるクイズ |
| **鍵盤** | 好きなキーで和音・スケールを光らせて弾ける。ブルース伴奏つき |

- 1画面1カードなので、ほぼスクロールしません
- 進み具合と耳トレの最高記録は、その端末のブラウザに自動保存されます

## おすすめの学び方

ジャズは「理論から」より **「耳から」** 入るほうが挫折しにくいです。

### 毎日10分のメニュー
1. **レッスンを1つ**（3〜5分）
2. **耳トレを10問**（3分）
3. **好きなジャズを1曲きく**（レッスンで習ったことを探しながら）

### ロードマップ（目安：2〜3週間）

| # | テーマ | ゴール |
|---|---|---|
| 1 | スウィング | 「タッカ タッカ」のノリと、2・4拍目の手拍子がわかる |
| 2 | セブンス和音 | maj7 / m7 / 7 の響きを言葉で説明できる |
| 3 | ii-V-I | ジャズの決まり文句を聴いて気づける |
| 4 | ブルース | 12小節を数えながら聴ける |
| 5 | アドリブ | ブルース・スケールで伴奏に合わせて弾ける |
| 6 | スタンダード曲 | 「枯葉」を聴いて、構成（テーマ→ソロ→テーマ）を追える |

### この順番にしている理由
- **リズムが最初**：ジャズらしさの大部分はスウィングのノリ。音を知らなくても体で分かります
- **和音は「気分」で覚える**：「明るい」「切ない」「緊張」と言葉に結びつけると耳に残ります
- **ii-V-I とブルースだけで、大半の曲の骨組みがわかる**
- **最後に実際の曲**：習ったパーツが本物の演奏の中で聴こえる体験がゴールです

## 公開のしかた（スマホで使う）
GitHub の **Settings → Pages** で、Branch をこのブランチ（またはmain）・フォルダを `/ (root)` にして保存すると、
数分後に `https://<ユーザー名>.github.io/jazz-learning/` で開けるようになります。

## ファイル構成
- `index.html` … 画面の骨組み
- `style.css` … 見た目
- `app.js` … 音・レッスン内容・クイズ（レッスン文章は `LESSONS` の中にあります）
