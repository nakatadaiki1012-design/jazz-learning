# ジャズ・ステップ 🎷

ジャズ初心者が「聴いて・わかって・弾いてみる」まで進める、スマホ向けの学習アプリです。
インストール不要。ブラウザで `index.html` を開くだけで動き、**音もアプリ内で鳴ります**（音源ファイル不要）。

## アプリの画面（3つだけ）

| タブ | できること |
|---|---|
| **学ぶ** | 4本の柱・9つのレッスンをカード形式で1枚ずつ進める。各レッスンに「楽器で弾こう」カードつき |
| **耳トレ** | 「和音当て」と「まねっこ」（聴いたフレーズを**自分の楽器**か画面の鍵盤でまねる） |
| **練習** | ii-V-I／ブルース／枯葉の伴奏に合わせて弾く。今弾く場所が伴奏に合わせて自動で切り替わる |

## 楽器の前に置いて使う

最初に楽器をえらぶと（右上でいつでも変更可）、「どこを弾くか」をその楽器の形で表示します。

| 楽器 | 表示 |
|---|---|
| ピアノ | 鍵盤。左手＝根音、右手＝3度・7度（青） |
| ギター | 指板。「3度・7度」ではジャズギターの基本形「シェル・ボイシング」を、前のコードから近い場所で表示 |
| ベース | 指板（低い位置を優先）。**伴奏からベースを抜く**ので、自分が土台になって弾ける |
| アルト／テナーサックス・トランペット | 吹く音を大きく表示。**移調して譜面の音名で表示**（例：実音 Dm7 → アルト譜 Bm7） |
| 歌・その他 | 実音の音名で表示 |

- 見せる音は「根音／3度・7度／和音／スケール」から選べる
- テンポは −／＋ で 60〜200 まで（ゆっくり練習できる）
- 伴奏はくり返し再生。再生中は画面が消えないようにする（対応ブラウザのみ）
- 音名は「E7 の3度＝G#」のように、楽譜どおりの♯／♭で表示

## 学び方の考え方：ジャズは「言語」として身につける

ジャズは楽譜を正確に再現する音楽ではなく、**言葉を覚えるのと同じ順番**で身につきます。
耳で聴いてまね（耳コピ）、単語を覚え（語彙）、ルールを知り（文法）、会話する（インタープレイ）。
このアプリは、その流れを **4本の柱** に整理しています。

| 柱 | レッスン | 身につくこと |
|---|---|---|
| **1 リズム**（一番大事な土台） | 1. スウィングのノリ / 2. 2・4拍と後ノリ | 3連符ベースの跳ね、テンポで変わる跳ね具合、2・4拍の重心、裏拍アクセント、後ノリ |
| **2 文法**（和音と進行のルール） | 3. セブンス和音 / 4. ii-V-I / 5. ガイドトーン / 6. ブルース12小節 | maj7・m7・7の響き、決まり文句ii-V-I、3度と7度のなめらかなつながり、12小節の型 |
| **3 語彙**（名演のフレーズをまねる） | 7. 耳コピ入門 | 聴く→歌う→弾く、フレーズを分解して他のキーへ移す |
| **4 実践**（制限して弾く・会話する） | 8. 制限してアドリブ / 9. スタンダード曲 | 3音だけのアドリブ、コール＆レスポンス、「枯葉」をベース→ガイドトーン→耳コピで身につける |

### 毎日10分のメニュー
1. **レッスンを1つ**（3〜5分）
2. **耳トレを10問**（和音当て・まねっこ）
3. **好きなジャズを1曲きく**（レッスンで習ったことを探しながら）

### あえて入れていないもの
テンション（9th・11th・13th）やオルタード・スケール（♭9・♯9など）は、上の4本柱が身についてからの上級編です。
初心者のうちに入れると混乱しやすいので、今は扱っていません。

## 公開のしかた（スマホで使う）
GitHub の **Settings → Pages** で、Branch をこのブランチ（またはmain）・フォルダを `/ (root)` にして保存すると、
数分後に `https://<ユーザー名>.github.io/jazz-learning/` で開けるようになります。

- `style.css` … 見た目
- `app.js` … 音・レッスン内容・クイズ（レッスン文章は `LESSONS` の中にあります）
